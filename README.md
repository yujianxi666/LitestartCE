## 更加个性化的Litestart二次开发版

LitestartCE 保持了原版Litestart"干净、快、类原生"的特点，同时增加了更多的自定义选项：

- 🎨 **主题模式调节**：跟随系统 / 深色 / 浅色三档手动切换；
- 📐 **布局微调**：各元素间距、位置偏移、元素对齐（左端 / 居中 / 右端）调节选项
- 🧩 **元素间距，大小微调**：搜索框，引擎logo与快速链接形状与大小微调
- ★ **背景模糊调节**：壁纸模糊程度调节

### 与原版的差异一览

| 项目 | Litestart（原版） | LitestartCE（本分支） |
| --- | --- | --- |
| 主题模式 | 仅跟随系统 | 跟随系统 / 深色 / 浅色，手动可选 |
| 布局微调 | 固定间距与居中 | 间距、水平/垂直偏移、对齐，大小，形状均可调 |
| 设置入口 | 布局为独立弹窗 | 合并为设置面板第二页，左右滑动，方便预览 |
| 更新源 | XingYueFox/Litestart | yujianxi666/LitestartCE |

> 原版的其余功能（搜索引擎、快速链接、搜索历史、自定义背景、配置文件导入导出、多语言等）在 LitestartCE 中完全保留，用法一致。

## 快速开始

1. 从 [Releases](https://github.com/yujianxi666/LitestartCE/releases) 下载最新的 `.zip` 文件（FireFox使用.xpi），或者直接克隆本仓库
2. 打开浏览器的扩展管理界面（`chrome://extensions`、`edge://extensions` 或 `about:debugging`），启用**开发人员模式**
3. 将解压后的文件夹通过「加载已解压的扩展程序」载入
4. 在扩展列表中找到 **LitestartCE** 并启用，新标签页即会替换为本页面

## 关于 LitestartCE

<img alt="215014" src="docs/pics/2002.webp" />

- 面向桌面浏览器可定制的类原生浏览器起始页
- 相比之下，这个页面没有无关紧要的在线内容，提升了新标签页的加载速度
- 在相对更多个性化的同时也可以享受到极致的速度
- 所有设置与数据都保存在你的浏览器本地

> 仓库内 `docs/pics` 下拥有ce后缀的截图来自 LitestartCE（本分支）；
> 主题模式、布局微调等新增项以实际页面为准。

## 特色功能

- 你可以随意更改搜索引擎，并且拥有 logo 标题，网站导航，搜索历史亦或者是搜索框的位置将由您决定
- 自定义背景、搜索引擎以及布局
- 固定你所想放在此处的网站
- 亦或是任何一个视频/图片壁纸
